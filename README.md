# 蓝染工坊 · v17

可直接使用的单文件 H5。入口为 `index.html`，图片、代码和音乐均已内嵌；无需部署或联网加载素材。Node.js 24.15+ 环境可运行 `npm start`，在 `http://localhost:4173` 预览。

## 创作

- 方巾、帆布袋、围巾、T 恤在横向轮播中选择。物件轮廓用于画蜡、浸染、去蜡、清洗、晾晒和收藏；帆布袋提手保留棉白。围巾展开制作，成品以系起的形式呈现。
- 选择物件后再选择蜡染或扎染。编辑区不切换染法，返回物件页可重新选择。两种染法各自保留制作输入和撤销历史。
- 蜡染支持画笔、擦蜡、纹样及整幅照片明暗转蜡稿。照片可调留白、细节和染色深浅，不进行主体分割。
- 扎染使用连续的 25×25 顶点布面，分别捏布、揉布、划线折布和系绳。UV 坐标保留原布位置；系绳记录被绳子穿过的材料位置，解结后展开。WebGL 负责实时纹理与层叠，提供 Canvas 降级显示。
- 浸泡累计最多 20 秒。提前捞出后，圆形补浸按钮可继续浸泡；累计到时自动捞出。已用染液锁定，继续浸泡只加深同一份纹样。
- 蜡染去蜡、扎染解结后清洗。清洗改用倾斜浇水壶、连续水流与湿布起伏。靛蓝在清洗后晾晒时逐渐从青绿氧化为蓝色。
- 「吹气」和「扇风」并排，吹气为主按钮；麦克风音量影响风力，扇子有摆动动画。不操作时仍有微风。

## 音乐与保存

音乐默认请求播放。浏览器不允许自动播放时，第一次用户操作会再次尝试。顶部声音按钮可关闭/播放，麦克风收音时暂停音乐。首页「设置说明」保留音乐来源、CC0 授权链接和麦克风说明。

照片和声音均在本机处理，不上传、不录音。麦克风取决于 HTTPS / localhost 和浏览器许可；真实手机与小红书宿主的权限、保存桥接仍需集成验证。

作品存于当前来源地址的 IndexedDB，最多 50 幅；超出时保留待收藏作品，不自动覆盖。使用「保存作品」导出 PNG 或海报。切换浏览器、从 file 地址换成 localhost 或清理浏览器数据会影响收藏可见性。宿主可提供 `IndigoHost.saveImage({blob,fileName})`。

## 开发与检查

```sh
npm run build
npm run check
npm test
```

`index.html` 与 `dist/index.html` 是相同的构建产物，请修改 `src/` 后重新构建。`npm run verify` 连续完成上述三步。

当前 16 组回归覆盖物件轮廓、补浸累计与颜色、两种染法独立历史、整布手势和 UV 防染、照片明暗、配方、清洗和风效、作品收藏与导出。自动化测试中的麦克风为模拟输入；界面截图另行在真实浏览器检查。

Windows 的部分 Skia 包未附 ICU 数据，测试脚本会将本机已安装 Edge 的 ICU 数据与当前 Canvas 原生模块复制到临时测试目录；不下载依赖，不改变浏览器安装。此补充仅用于测试，不进入单文件成品。

主要源码：`items.js` 负责四种物件与轮播；`editor.js` 负责蜡稿；`tie-plan.js` / `cloth-gpu.js` 负责整布交互；`textile.js` / `material.js` 负责材质；`ritual.js` / `audio.js` 负责制作流程、风与音乐；`gallery.js` / `export.js` 负责保存。历史 `cloth.js` / `ties.js` 仍保留，不参与当前整布交互。

## 模拟范围

这是记录材料位置和防染关系的视觉创作体验。布面采用受约束的近似变形，清洗、氧化和绳索采用可交互动画，未求解真实流体、化学反应或完整织物自碰撞。照片的原始明暗和背景都会参与蜡稿；不会自动把白底替换为蓝色。
